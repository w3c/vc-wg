The Verifiable Credentials Working Group has published a series of Draft Working Group Notes for the threat models of the respective specifications. The threat models are as follows:

  • Recognized Entities Threat Model v1.0
  • Data Integrity Threat Model v1.1

The Working Group welcomes comments via the GitHub repository issues; the respective repository URL-s can be found in the header of each document.

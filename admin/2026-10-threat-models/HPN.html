[Draft] First Draft Notes: Verifiable Credential Threat Models

The Verifiable Credentials Working Group has published a series of Draft Working Group Notes for threat models. All identify and analyze security and privacy threats specific to their respective rec-track documents. These threat models are as follows:

  • Recognized Entities Threat Model v1.0
  • Data Integrity Threat Model v1.1
  • Verifiable Credential Barcodes Threat Model v1.0
  • Verifiable Credentials Render Method Threat Model v1.0
  • VCALM Threat Model v1.0

The Working Group welcomes comments via GitHub repository issues; the respective repository URL-s can be found in the header of each document.
